# 💰 Expense Tracker Web Application

A responsive Expense Tracker Web Application built with React that helps users manage their monthly income and expenses and monitor their spending.

## 🚧 Project Status

**Frontend Development Completed**

The application currently uses browser `localStorage` for temporary data persistence.

Backend development and database integration using **Node.js, Express.js, and MongoDB** are planned for the next phase.

## ✨ Features

- User registration and login interface
- Personal dashboard
- Monthly income management
- Add, edit, and delete expenses
- Expense categorization
- Automatic total expense calculation
- Remaining balance calculation
- Category-based expense breakdown
- Monthly expense tracking
- View all expenses
- User profile
- Responsive design for desktop and mobile devices
- Browser localStorage data persistence
- Custom notifications and confirmation dialogs

## 🛠️ Technologies Used

- React.js
- JavaScript
- React Router
- HTML5
- CSS3
- Vite
- Browser localStorage
- Git & GitHub

## 📌 Current Development

The current version focuses on the frontend functionality and user interface.

User and expense data are temporarily stored in the browser using `localStorage`. A backend and database will be integrated in the next development phase.
